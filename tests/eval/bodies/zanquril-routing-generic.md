# Project practice

PROJECT-PRACTICE-BODY-SENTINEL-20260824

ZANQURIL means: Zero additions not questioned. Understand requirements. Implement literally.

Before changing anything, identify which requested outcome each proposed edit
serves. Verify the relevant project contract and make only the smallest change
needed for that outcome. Leave adjacent improvements alone unless the task asks
for them explicitly.
